## Platform Features

1. **Plotted Schemes Directory**: Browse active land developments across Godawari, Budhanilkantha, Bhaktapur, Pokhara, Chitwan, and Chandragiri with cadastral boundary coordinates, facing, road access, and price per Aana/Katha.
2. **Interactive Hero & Search**: Quick search filter by Location and Property Type with land and mountain visual backdrop blending.
3. **Nepal Land Unit Converter**: Instant bidirectional conversion between Hilly (*Ropani-Aana-Paisa-Daam*), Terai (*Bigha-Katha-Dhur*), and *Square Feet / Square Meters*.
4. **Loan EMI Calculator**: Real-time monthly installment, principal, and total interest calculation for land and home financing.
5. **Malpot Registration Tax Estimator**: Location-based registration fee and 25% female ownership concession calculator.
6. **Dark & Light Mode**: Complete theme toggle with system auto-detection and persistent preferences.
7. **Site Visit Booking**: Free weekly Saturday guided site tours with pickup from New Baneshwor.

## Tech Stack

- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4 + Framer Motion
- **State Management:** Zustand
- **Routing:** React Router 7 (Browser & Hash resilient fallback)
- **SEO & Pre-rendering:** Node.js static site generator pipeline (`post-build-seo.js`) with sitemap and robots.txt generation

## Local Development

